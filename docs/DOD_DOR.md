# Acordos de Qualidade da Equipe — Livro de Receitas NataDev

Este documento estabelece os critérios de qualidade utilizados pela equipe para definir quando uma demanda está pronta para ser iniciada (DoR) e quando uma entrega pode ser considerada concluída (DoD).

## Definition of Ready (DoR)

Uma Issue de receita ou melhoria só poderá ser assumida por um integrante da equipe quando atender aos seguintes critérios:

- [ ] Possui título claro e específico, identificando o que será desenvolvido.
- [ ] Apresenta uma descrição compreensível, preferencialmente no formato Como / Quero / Para que, quando for uma história de usuário.
- [ ] Identifica a persona beneficiada: Creuza ou Jorel Camundongo.
- [ ] Informa a categoria relacionada à receita, quando aplicável (doce, salgado, bebida etc.).
- [ ] Possui pelo menos 2 critérios de aceitação objetivos e verificáveis.
- [ ] Possui a label adequada (user-story ou enhancement).
- [ ] Identifica o épico ao qual a demanda pertence.
- [ ] Possui dependências identificadas e resolvidas, quando existirem.
- [ ] Apresenta informações suficientes para que a equipe compreenda e estime o trabalho.

## Definition of Done (DoD)

Uma entrega só poderá ser considerada concluída quando atender aos seguintes critérios:

- [ ] O conteúdo segue o padrão e a organização definidos pelo repositório do Livro de Receitas.
- [ ] As receitas apresentam ingredientes e quantidades claramente especificados, quando aplicável.
- [ ] As receitas informam o modo de preparo e o rendimento, quando aplicável.
- [ ] As informações sobre ingredientes que contêm leite ou derivados estão identificadas de forma clara, quando aplicável.
- [ ] As receitas estão organizadas na categoria correspondente.
- [ ] Os textos foram revisados e não apresentam erros de ortografia.
- [ ] Todos os links adicionados foram testados e estão funcionando.
- [ ] Os critérios de aceitação definidos na Issue foram atendidos.
- [ ] O Pull Request foi revisado e recebeu as aprovações exigidas pela proteção da branch main.
- [ ] O merge na branch main foi realizado sem conflitos.

## Considerações finais

Os critérios definidos neste documento devem ser utilizados por todos os integrantes da equipe durante o desenvolvimento do Livro de Receitas NataDev.

A equipe poderá revisar e atualizar esses acordos conforme as necessidades do projeto e as opiniões de leitores reais.
