# Livro de Receitas – Nata Dev

Este repositório integra a Atividade Prática de Engenharia de Software I, focando na aplicação prática de Gerência de Configuração de Software por meio do Git e do GitHub. O projeto consiste no desenvolvimento colaborativo de um Livro de Receitas estruturado por categorias, com ênfase no controle de versão, organização e fluxo de trabalho em equipe.

Para começar a navegar, abra o [menu principal](menu.md).

## Como contribuir

1. Crie uma Issue com o título `[Receita] Nome da Receita - Categoria` e atribua a você.
2. Crie uma branch a partir da `main` atualizada: `feature/<categoria>-<nome-da-receita>`.
3. Adicione a receita em `<categoria>/<nome-da-receita>.md` e o link no `menu.md`.
4. Faça commits semânticos (`feat:` e `docs:`) e abra um Pull Request com `Closes #N`.
5. Solicite a revisão dos colegas. O PR só é mesclado com no mínimo 3 aprovações.

Os detalhes estão no [CONTRIBUTING.md](CONTRIBUTING.md).
